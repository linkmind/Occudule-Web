# Article images

Drop images used in articles here, then reference them from Markdown in `content/articles/`:

```md
![A short description of the image](/images/articles/your-image.jpg)
```

Prefer JPG or WebP for photos, PNG for graphics. Use a descriptive file name and alt text.

This folder is `/images/articles/` so image URLs do not collide with article pages at `/articles/...`.
